# 内容素材工程

把本地大量文稿整理成可持续生长的内容工程：内容单元库 + 主题地图 + 选题装配 + 关系与去重索引。

## 当前状态

- 模式：审计/样本/批量/全量（见 `03-处理状态/处理状态总览.md`）
- 素材规模与处理进度：见 `03-处理状态/原始素材索引.md`
- 单元数量与健康度：运行 `node 07-脚本与工具/summarize-system.js` 查看

## 快速入口

- 协作规则：`AGENTS.md`
- 权威顺序：`SOURCE_OF_TRUTH.md`
- 最短启动链路：`docs/quickstart.md`
- 验收标准：`docs/acceptance.md`

## 本系统不做什么

单篇润色、标题优化、零散素材轻量整理。这些请求不进入本工程。
