# SOURCE_OF_TRUTH.md — 权威定位与冲突规则

## 本工程是什么

一个本地内容素材工程：把大量文稿拆成可复用、可追溯、可重组的内容单元，并维护主题地图、选题装配稿与各类索引。

## 权威顺序（冲突时以谁为准）

1. **原始素材副本**（`01-原始素材区/`）：事实的最终权威。单元与原文矛盾时，查原文
2. **规则文件**（`00-规则与索引/`）：字段、关系、去重口径的权威。脚本与习惯做法和规则矛盾时，以规则为准
3. **内容单元当前版本**（canonical=true）：观点与定义的权威；历史版本不参与判定
4. **状态层**（`03-处理状态/`）：全部可由脚本重建；它出错时重建，不手改
5. **主题地图与装配稿**：导航与骨架，永不作为内容依据

## 冲突处理

- 两个单元冲突 → 不合并，登记 冲突 关系，引用时由成稿人取舍
- 单元与原文冲突 → 以原文为准修单元，version +1 并记录
- 脚本输出与状态文件不一致 → 重跑脚本，状态文件可随时重建
