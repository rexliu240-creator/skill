# 新增文稿进入系统流程

## 触发

用户拿来一批新文稿（或单个文稿）要求纳入内容素材工程。

## 流程

1. **确认边界**：新文稿纳入哪个来源类别？是否有明确不纳入的部分？说不清就先问，不猜
2. **复制副本**：按 来源规则.json 把文稿复制到 `01-原始素材区/完整副本/` 对应目录；原文件不动
3. **刷新登记**：运行
   - `node 07-脚本与工具/generate-source-registry.js`
   - `node 07-脚本与工具/rebuild-processing-ledger.js`
4. **判断处理方式**：
   - 工程尚在样本模式 → 只挑代表性 1~2 篇进入样本抽取，其余留在待处理清单
   - 工程已过样本闸门 → 按批次纳入，每批数量与之前批次保持一致量级
5. **抽取与校验**：按 处理流程.md 的标准链路执行；新单元必须过字段、关系、去重三道校验
6. **刷新状态**：运行 `node 07-脚本与工具/summarize-system.js`

## 红线

- 不跳过复制副本直接改写原文件
- 不因为"就一篇"而跳过来源分类
- 不把新文稿和新工程混在旧目录里处理
